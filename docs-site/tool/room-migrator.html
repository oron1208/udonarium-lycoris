アドバンス部屋データ変換ツール

ユドナリウム / FLY / 2D / リコリス通常部屋のzipを、
ユドナリウムリコリスのアドバンス部屋向けzipへ変換します。

IMPORTANT

安全性について

  • 変換処理はすべてブラウザ内で行われます。zipはサーバーへ送信されません。
  • ファイルサイズ上限は 50MB です。
  • 元zipは変更されません。変換後zipを別名でダウンロードします。
  • このツールは変換後データの動作を保証するものではありません。特殊な派生版データは一部変換できない場合があります。
  • 必ず元データを保管し、変換後は実際の卓で使う前に動作確認してください。

部屋データzipを選択

STEP 2

変換内容

✅ 各 game-table をアドバンス部屋化（roomMode="advanced"）
✅ 照明・視界・戦闘管理・ダイスカットイン系の不足属性を初期値で補完
✅ 画像・音声などXML以外のファイルはそのまま維持
