チャットパレット

戦闘・魔法・台詞をタブで整理。
選んだタブだけを、まとめてテキスト編集できます。

目次

  1. 分類タブを使う
  2. 現タブ全文編集
  3. 全体の編集との使い分け
1

分類タブを使う

コマの右クリックメニューから「チャットパレットを表示」を選びます。パレット内の「＋ タブ」で「戦闘」「魔法」などの分類を作れます。

「すべて」は全タブの一覧、「共通」は分類タブの外にある本文です。タブ名を押すと、そのタブの内容に切り替わります。

2

現タブ全文編集

  1. 編集したい分類タブ（例：戦闘）を選びます。
  2. 「追加・編集」を開き、「現タブ全文編集」を押します。
  3. そのタブの本文だけがテキスト欄に入るので、まとめて編集します。
  4. 「保存」で反映します。変更しない場合は「キャンセル」を押します。

画像を押すと大きく表示できます。タブ名やほかのタブは変更されません。空行や折りたたみの中も含めて編集でき、「共通」を選んだ場合は共通欄だけが対象になります。

本文を空にして保存しても、名前付きタブ自体は残ります。「すべて」表示中は対象が決まらないため、先に編集したいタブを選んでください。

3

全体の編集との使い分け

  • 現タブ全文編集：いま選んでいるタブの本文を、まとめて直したいとき。
  • 全文テキスト編集：タブの区切りも含め、パレット全体をまとめて直したいとき。
  • タブ名変更・タブごと削除：タブ自体の名前や構成を変えたいとき。

編集中に別の画面や参加者から本文が更新された場合は、上書きせずにお知らせします。入力中の内容を控えてから、キャンセルして開き直してください。
