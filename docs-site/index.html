v1.53
2026-07-03

BGM再生バグ修正・一括判定式対応強化・チャットパレット連携

  • BGMが鳴らない不具合を修正 — 保存部屋読み込み時にテーブルBGM設定が空でも優先度システムが作動し、ジュークボックスBGMが上書きされて無音になる問題を解消。テーブル音源レイヤーが実際に存在しない場合は優先度判定から除外するよう修正
  • 一括判定ダメージパネルの式評価を強化 — 固定値（15）、計算記法（c(8+{Artificer})）、独自ダイスボットコマンド（AR{敏セーヴ}>=0）、単純数式（8+5）に対応。BCDice → 固定値 → 数式 → 数値抽出の順でフォールバック評価
  • チャットパレット参照の入れ子対応 — {Artificer}の値が({知力}+{習熟})になっているような多段参照を最大32回ループで解決するよう修正
  • 対抗ロールカットインにチャットパレットピッカーを追加 — 攻撃側・受動側・ダメージ式の横に📜ボタンを配置し、キャラのチャットパレットから式を選択可能に
  • 一括判定ダメージパネルにチャットパレットピッカーを追加 — 命中式・ダメージ式・受動式の横に📜ボタンを配置
  • 対抗ロールカットインのキャラ画像表示を修正 — blob URLがAngularのサニタイザでunsafe:扱いされて表示されない問題を修正
  • 不要なシステムメッセージを抑制 — 「画像データはサーバーから削除されました」のシステムメッセージをコンソールログのみに変更
  • 画像の自動圧縮 — ドラッグ＆ドロップで画像をアップロードする際、2MBを超える画像を自動的に圧縮（最大1920px、JPEGはquality 0.85、PNGは透過保持）するように変更。大きい画像でも弾かれずにアップロード可能に

  • 戦闘順トラッカーをドラッグで並び替え — テーブル上の戦闘順パネルのエントリをドラッグ&ドロップで並び替え可能に（GM限定）
