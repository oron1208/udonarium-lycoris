ABOUT

ユドナリウムリコリスとは

🌐

ブラウザ完結

インストール不要。ブラウザを開くだけでTRPGのオンラインセッションが始められます。

🕯️

照明システム

松明・魔法の光・レーザー。壁による光遮断も再現する、こだわりの照明エンジン。

🎵

ジュークボックス

BGM・SE・環境音の3モード。雰囲気たっぷりのサウンドでセッションを盛り上げます。

🎭

VNモード

ビジュアルノベル風の立ち絵表示。キャラクターの表情でシーンを彩ります。

アップデート履歴

v1.32
2026-06-11

地形スナップ修正

  • コマを立体地形から平面に移動した際、Z座標がリセットされず浮いたままになる問題を修正
  • 地形自身を移動した際に少しずつ上昇していく自己スナップ問題を修正
  • 地形との当たり判定でグリッドサイズが考慮されていなかった問題を修正
v1.31
2026-06-10

音声同期修正・パフォーマンス改善

  • 複数の音声ファイルを同時アップロードした際、2曲目以降のファイル名がハッシュ値になる問題を修正
  • 部屋から退出後もアドバンスモードのUIが残る問題を修正
  • アドバンスモード時にサイドメニューに「ADVANCED」バッジを表示
  • アドバンスモードで壁を設置した際の重さを改善（壁グリッドキャッシュ最適化）
  • ファビコンをリコリスオリジナルデザインに変更
v1.30
2026-06-10

アドバンスモード追加

  • 視界管理・所有権管理・ダイスロール演出強化の拡張部屋モードを追加
  • コマの所有権設定を追加。自分のコマだけ操作可能に
  • コマの視線範囲を設定可能。戦闘の視界シミュレーションに
  • BCDiceの全ダイスロールで自動カットイン演出。キャラアイコン・クリティカル/ファンブル演出付き
v1.22
2026-06-01

コマ演出・光源強化

  • コマの向きを表示する正面マークを追加。平面モードではドラッグで回転可能
  • 照射形状に「レーザー」を追加。壁で遮断される直線光
  • 光源タイプを「松明」「魔法の光」「懐中電灯」の3種類に整理
  • 魔法の光にソナー風の脈動リング表現を追加
v1.21

VNモード安定化

  • VNモードON時のログインフリーズを修正
  • 後から入室したプレイヤーにも立ち絵が正しく同期されるよう修正
  • 他プレイヤーのVNチャット吹き出し表示に対応
  • パフォーマンス改善
v1.20

照明システム・VNモード追加
