# v2.2公開とv2.0への復旧

公開日: 2026-10-13。v2.2はAngular 22・esbuild分割・zonelessへの移行を含む大規模な更新。
不具合時には、基盤変更前にVPSで実際に動いていたv2.0へ戻す。

## 保存済みのv2.0

- Gitの復旧点: `pre-v2.2` → `c4003e58a125236f21d7e29187d89c08a55767e6`。
- VPSバックアップ: `/root/release-backups/pre-v2.2-20261013/`。
- 正確な旧main: `main.5a20bc1e0ea8f5b4.js`。
- 配信資産全部: `webroot-v2.0.tar.gz`。旧index・公式HP・セルフホストZIPも同ディレクトリに保存。
- 旧コンテナのスナップショット: `udonarium-lycoris:rollback-v2.0-20261013-pre-v2.2`（別名 `:2.0`）。
- ローカルの同一資産: `tmp/release-v2.2/rollback/udonarium-lycoris/`。

## 即時復旧（指示が出たときだけ実行）

VPSにSSHして、次の1コマンドを実行する。

```bash
bash /root/release-backups/pre-v2.2-20261013/rollback-v2.0.sh
```

配信資産を先、indexを最後に戻し、公式HPもv2.0の案内へ復旧する。
新しいハッシュ付き資産は消さず、`data/`・音楽ライブラリ・認証設定には触れない。
通常の復旧ではコンテナを止めたり作り直したりしない。
全旧資産のSHA256とAPI状態を検証し、Dockerの`:latest`も保存済みv2.0へ戻す。
接続中のブラウザは旧コードへ自動で切り替わらないため、参加者にはZIP保存のうえ再読み込みを案内する。

ローカル配信も戻す場合は、プロジェクトルートで次を実行する。

```bash
python3 scripts/rollback-v2.0-local-20261013.py
```

ソースやGit履歴はこの操作では巻き戻さない。v2.2の修正履歴を残したまま、
必要なら`pre-v2.2`を別worktreeへcheckoutして修復・再ビルドできる。
既存の卓データをバックアップ時点のデータで上書きする復旧は行わない。

## v2.2の変更範囲

- Angular 22、初期バンドル分割、zonelessへの移行。
- ObjectStoreの削除履歴GC・同一tick連続更新の同期修正。
- esbuildでのBCDice遅延ロード、SW2.5の括弧計算コマンド修正。
- VNログの丸い立ち絵アイコン、添付画像との分離、スクロールバー整理。
- 別ウィンドウの更新通知、ダイスカットインの発言者画像取得。

新しい任意のチャット属性`imageKind`は立ち絵と添付の区別に使用する。
旧ログには必須にしない。v2.0はこの属性を表示判定に使用しない。
通信サーバー・認証設定・HTTP2設定は今回の公開で変更しない。
