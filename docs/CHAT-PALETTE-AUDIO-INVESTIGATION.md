# チャットパレット音声連携 調査メモ

作成日: 2026-06-25
復元日: 2026-06-25

## 結論

チャットパレットから音声を鳴らす機能は実装可能。
ただし、現時点では実装保留。

## 調査した方向性

- チャットパレットの実行時に、特定記法から音声再生を呼び出す
- ジュークボックス/AudioStorage/AudioSharingSystem の既存音声管理に接続する
- 音声ファイルはサーバーメディア保存方式と整合させる

## 注意点

- チャットパレットは頻繁に使われるため、誤爆再生を防ぐUI/記法が必要
- 参加者全員に鳴らすのか、自分だけ鳴らすのかを明確にする必要がある
- 音声素材は著作権・共有・サーバー保存の注意表示対象
- 部屋zipには音声本体を同梱せず、hash参照 + サーバー再取得の方針を維持する

## 実装保留理由

先に以下を優先するため。

- 平面コマ表示改善
- インベントリ拡張
- サーバーメディア保持/GC/消失通知
- 利用規約・削除対応・dev-admin管理機能
