# ユドナリウム リコリス v1.9 リリースノート（v1.70 からの変更点）

リリース日: 2026-10-07

v1.70（2026-09-07）以降の変更をまとめたもの。

## 新機能

### 辞書機能の大幅拡張
- **辞書を自作できる**: 辞書パネルから「＋作成」で、コマ辞書／資料辞書／チャパレ辞書のタイプを選んで好きな数だけ作成。切り替え・名前変更・削除（確認ダイアログ付き）に対応。
- **辞書内検索**: コマは名前＋タグ、資料はセクション名＋ページ本文、チャパレは名前＋中身を対象に部分一致検索。
- **コマ保存ZIP（data.xml）の取り込み対応**: ユドナリウムでコマを保存したZIPをそのまま読み込める。キャラコマサイト系の character.xml 形式・`<キャラ名>.xml` 形式も引き続き対応。
- **ユドナリウム保存形式の完全対応**: キャラ名・画像参照がデータ要素（`<data name="name">` / `<data type="image" name="imageIdentifier">`）に入っている形式に対応。複数画像（立ち絵・差分など）も全て辞書に登録される。
- **登録先を選べるピッカー**: 卓上コマの右クリック「辞書に登録」で、登録先の辞書を一覧から選択。前回使った辞書を記憶し、登録完了メッセージを表示。
- **チャパレのドラッグ＆ドロップ**: 辞書のチャパレ行を卓上コマにドラッグ＆ドロップで追記適用（置換はパネルのボタン）。
- **再取り込みでの自動補完**: 同じZIPを再読み込みすると、旧バージョンで登録した画像なし・無意味名（「data」等）のエントリに画像と正しいキャラ名を自動補完。エントリは増えない。

### チャパレ・チャットの別ウィンドウ化
- チャットパレットとチャットを独立した別ウィンドウで開ける（オーナー別ブリッジv2）。サブディスプレイでの運用に便利。

### チャットログ検索・画像貼り付け
- チャットログをキーワードで検索するパネルを追加。
- クリップボードの画像をチャット入力欄に直接貼り付け（Ctrl+V）して送信できる。

### 戦闘BGMの再設計
- 戦闘BGM再生中でも、ミニプレイヤー・ジュークボックスからの曲選択を優先する（手動オーバーライド方式）。戦闘BGMの開始トリガーで手動制御はリセットされる。
- テーブル設定BGMが鳴っている卓でも、ミニプレイヤーで選んだ曲を優先して再生。

### UI改善
- 削除ボタンを赤背景＋黒文字に変更（視認性改善）。
- チャットパレットの行折り返し表示のローカル設定を追加。

## 修正
- ミニプレイヤーで楽曲選択（変更）が反映されない問題を修正（BGM優先度エンジンのテーブルBGMが常に勝つ問題）。
- 辞書へのZIP取り込み関連の不具合を修正: コマ保存ZIPが0件登録になる／名前が「data」になる／画像が反映されない、の各問題。
- バフマネージャーの不具合2件を修正。
- 戦闘BGMのジュークボックス制御を修正。

## 技術メモ（開発用）
- 辞書: `DictionaryService`（IndexedDB `lycoris-dictionary` v2、辞書コレクション対応）、`DictPickerComponent`（登録先選択）、検索はパネルの `searchText` フィルタ。
- ZIP取り込み: `registerCharacterZip` が data.xml / character.xml / `<名前>.xml` に対応。画像は identifier=拡張子なしファイル名で ImageStorage 復元。imageIdentifier 不一致・無しは1枚画像で自動紐付け/注入。データ要素形式の `<data name="imageIdentifier">` 収集対応。重複ガード時に既存エントリを補完（画像追加・無意味名リネーム）。
- チャパレD&D: 辞書パネル `onPaletteDragStart`（text/lycoris-dict-palette）→ game-character の drop で `applyPaletteToCharacter(..., 'append')` + 効果音。
- BGM優先度エンジン: 戦闘BGM＞テーブル設定BGM＞ジュークボックス。`_tableBgmManualOverride` を導入し、ユーザー明示操作（play/stop/playJukeboxLayers）でテーブルBGMを黙らせ、playTableAudio（卓切替・明示再生）で解除。
- E2E: `tools/verify-dict*.cjs`、`tools/verify-miniplayer.cjs`、`tools/verify-img.cjs`（実物ZIP込み27/27 PASS）。
